STRESS-REST — VERSION 19

This package starts from the previously approved v17 application and applies only the agreed refinements. It does not replace the logo with a new design.

Included files:
- index.html
- sw.js
- manifest.webmanifest
- icon.svg
- README.txt

Refinements:
- Preserves the approved Stress-Rest infinity symbol, red-to-orange-to-gold-to-green palette, and STRESS ↔ REST wordmark. The existing mark is animated with a restrained left-to-right gradient flow and subtle breathing; no extra tagline or decorative circle is added.
- Places the Stress-Rest Index number in the open centre of the gauge, visually between the arc ends.
- Keeps Performance Mode within one fixed screen without internal scrolling.
- Retains the existing organic ring silhouette while making its glow brighter and softer.
- Uses clean, light system sans-serif typography for the affirmations and reflections.
- Removes the Reflection 1–4 counter.
- Preserves the existing check-in model, calculation logic, history structure, and localStorage key stress-rest-tracker-v2.

INSTALLATION
1. Export a CSV backup from the app before replacing files.
2. Unzip this archive.
3. Upload all five files to the ROOT of the GitHub Pages repository, replacing the matching files. Do not upload the containing folder.
4. Commit the changes, then close and reopen the app.

Your historical entries remain in the browser's local storage. The archive does not intentionally clear that data.
